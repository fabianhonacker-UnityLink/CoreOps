CoreOps Dashboard Demo · MOCKUP 005
===================================

Dies ist eine eigenständige Demo-/Mockup-Welt für CoreEngineStudio.
Sie patcht NICHT die CoreEngineStudio-Hauptseite.

Start:
1. ZIP entpacken
2. START_COREOPS_DEMO.bat doppelklicken
3. Browser öffnet die Demo automatisch

Build-Kennung:
COREOPS-MOCKUP-005

Enthalten:
- index.html
- assets/css/coreops.css
- assets/js/coreops.js
- START_COREOPS_DEMO.bat
- README_START.txt

Hinweis:
Die Demo nutzt Fake-Daten und Fake-UI. Sie ist für Screenshots,
Showroom-Präsentation und Designbewertung gedacht, nicht als echte App.

Wenn Python installiert ist, startet die BAT einen lokalen Server unter:
http://localhost:5177

Falls kein Python vorhanden ist, öffnet die BAT die index.html direkt.
